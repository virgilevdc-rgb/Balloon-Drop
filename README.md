# Balloon Drop

Un jeu mobile : glisse le ballon au-dessus de la plateforme, garde le doigt posé pour le gonfler (x2, x3), puis lâche.
Le ballon rétrécit à chaque manche.

- Mode infini, Chrono (60 secondes) et Zen
- Aventure : le Ciel, l'Orage et le Volcan, avec un boss au bout de chaque monde
- Défi du jour, missions, 40 trophées et plus de 50 ballons à collectionner

Sur iPhone : ouvre le jeu dans Safari, touche Partager, puis « Sur l'écran d'accueil ».

Créé par Virgile, avec Claude.
